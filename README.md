# 💻 Exercicio HTML

Este projeto é uma prática de estruturação básica de páginas web utilizando HTML e CSS. A ideia principal foi aplicar conhecimentos de marcação, semântica e estilização.

---

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3

---

## 📱 Responsividade

O layout foi desenvolvido pensando em diversos tamanhos de tela, com uso de `media queries` para adaptar o conteúdo em dispositivos móveis, tablets e desktops.
